## Agence et vente

| Terme | Définition |
| --- | --- |
| **SMMA** | *Social Media Marketing Agency* : agence vendant des services de visibilité digitale à des entreprises. |
| **Prospect** | Personne ou entreprise qui pourrait devenir cliente. |
| **Lead** | Prospect qui a manifesté un intérêt (réponse, demande de devis, rendez-vous). |
| **Niche** | Segment précis de clients (ex. : artisans du bâtiment de ta ville) sur lequel tu te spécialises. |
| **Scraping** | Extraire automatiquement des informations publiques (nom, téléphone, site…) depuis une source comme Google Maps. |
| **Cold call** | Appeler quelqu'un qui ne t'attend pas. |
| **Cold e-mail / DM** | Message écrit envoyé à un prospect qui ne t'attend pas. |
| **Audit** | Analyse rapide de la présence en ligne d'un prospect, qui sert d'ouverture commerciale. |
| **Maquette** | Version de démonstration d'un site ou d'un visuel, montrée avant la vente. |
| **Appel de découverte** | Premier rendez-vous où tu poses des questions pour comprendre le besoin avant de proposer. |
| **Closing** | Le moment où un prospect dit oui et devient client. |
| **Objection** | Raison donnée par un prospect pour ne pas acheter (« trop cher », « pas le temps »…). |
| **Proposition commerciale** | Document qui présente le problème, la solution, le périmètre, le délai et le prix. |
| **Périmètre** | Ce qui est inclus — et exclu — de la prestation. |
| **Onboarding** | Mise en route d'un nouveau client : accès, informations, planning. |
| **Récurrent (MRR)** | Revenu mensuel récurrent : ce que tes abonnements clients rapportent chaque mois. |
| **Churn** | Part des clients qui arrêtent sur une période. |
| **Upsell** | Vendre une prestation supplémentaire à un client existant. |
| **Panier moyen** | Montant moyen facturé par client. |
| **Taux de conversion** | Part des prospects qui passent à l'étape suivante (contact → rendez-vous → client). |
| **CRM** | Outil (ou tableur) de suivi des prospects et clients. |

## Web et marketing

| Terme | Définition |
| --- | --- |
| **Fiche Google Business (GBP)** | Fiche d'entreprise affichée sur Google Maps et la recherche locale. |
| **SEO local** | Optimisation pour apparaître dans les recherches locales (« plombier + ville »). |
| **Community management** | Gestion des réseaux sociaux d'une entreprise : publications, réponses, animation. |
| **UGC** | *User Generated Content* : contenu au style « créé par un client », souvent en vidéo verticale. |
| **Ads / publicité payante** | Campagnes sponsorisées (Meta, Google, TikTok) facturées au clic ou à l'affichage. |
| **Nom de domaine** | Adresse d'un site (ex. : tonnom.fr), loué chaque année auprès d'un registraire. |
| **DNS** | Annuaire qui relie un nom de domaine à un serveur (enregistrements A, CNAME…). |
| **Hébergement** | Serveur qui rend un site accessible en ligne (ex. : Vercel). |
| **HTTPS / SSL** | Connexion chiffrée, signalée par le cadenas du navigateur. |
| **Workflow** | Suite d'actions automatisées (ex. : nouveau lead → ajout au CRM → message de bienvenue). |
| **n8n** | Outil d'automatisation no-code / low-code, auto-hébergeable ou en cloud. |
| **Prompt** | Instruction donnée à un outil d'intelligence artificielle. |

## Juridique et fiscal

| Terme | Définition |
| --- | --- |
| **EI** | Entreprise individuelle : l'entrepreneur exerce en son nom propre. |
| **Micro-entreprise** | Régime simplifié de l'entreprise individuelle : cotisations et impôt calculés sur le chiffre d'affaires encaissé. |
| **EURL** | SARL à associé unique : société à responsabilité limitée, gérée par un gérant. |
| **SASU** | SAS à associé unique : société par actions simplifiée, dirigée par un président. |
| **Émancipation** | Décision (du juge, ou effet du mariage) qui donne à un mineur de 16 ans ou plus la capacité d'un majeur pour la plupart des actes. |
| **Kbis** | Extrait qui officialise l'existence d'une société immatriculée au registre du commerce. |
| **SIREN / SIRET** | Numéros d'identification de l'entreprise (SIREN, 9 chiffres) et de chaque établissement (SIRET, 14 chiffres). |
| **Guichet unique** | Site de l'INPI (procedures.inpi.fr) par lequel passent toutes les formalités d'entreprise depuis 2023. |
| **Chiffre d'affaires (CA)** | Total des ventes encaissées ou facturées, avant toute dépense. |
| **Bénéfice** | Ce qui reste du chiffre d'affaires une fois les charges déduites. |
| **Trésorerie** | L'argent réellement disponible sur le compte à un instant donné. |
| **Cotisations sociales** | Prélèvements qui financent ta protection sociale (santé, retraite…), payés à l'URSSAF. |
| **IR / IS** | Impôt sur le revenu (payé par la personne) / impôt sur les sociétés (payé par la société sur son bénéfice). |
| **TVA** | Taxe sur la valeur ajoutée, collectée sur les ventes et reversée à l'État. |
| **Franchise en base de TVA** | Régime qui dispense de facturer la TVA tant que le CA reste sous certains seuils. |
| **HT / TTC** | Hors taxes / toutes taxes comprises. |
| **Acompte** | Partie du prix payée à la commande. |
| **CGV** | Conditions générales de vente : règles applicables à toutes tes ventes. |
| **Mentions légales** | Informations obligatoires sur l'éditeur et l'hébergeur d'un site web. |
| **RGPD** | Règlement européen sur la protection des données personnelles. |
| **ACRE** | Aide qui réduit les cotisations sociales pendant les premiers mois d'activité, sous conditions. |
| **CFE** | Cotisation foncière des entreprises, impôt local annuel (exonérée l'année de création). |
| **Plateforme agréée (PA)** | Prestataire immatriculé par l'administration fiscale par lequel transitent les factures électroniques. |
